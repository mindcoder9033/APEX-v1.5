Since this is a lightweight static web app (HTML, CSS, ES Modules JavaScript) without a `package.json` file, you can run a local server using any of the following commands in your terminal:

---

### Option 1: Using `npx serve` (Recommended)
```powershell
npx serve .
```
> Opens the app at **`http://localhost:3000`** (or `http://localhost:5000`).

---

### Option 2: Using `Python` (Built-in)
```powershell
python -m http.server 8000
```
> Opens the app at **`http://localhost:8000`**.

---

### Option 3: Using `npx http-server`
```powershell
npx http-server . -p 8000
```
> Opens the app at **`http://localhost:8000`**.
